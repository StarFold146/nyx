装一个自己的 Nyx

每一步：复制、粘贴、回车，看到什么就对一下下面写的。对不上就截图问人。Copy, paste, Enter, compare with what's written. If it doesn't match, screenshot and ask.

先分清三样东西

ChatGPT 聊天窗口只会聊天，碰不到你的服务器。
网页版 / 手机 app 里的 Codex在 OpenAI 的云上干活，改的是 GitHub 仓库，也碰不到你的服务器。
Nyx 里的 Codex装在你自己服务器上的那个，只有它能动你的机器。下面装的就是它。
ChatGPT chat and web/app Codex can't reach your server. Only the Codex installed inside Nyx, on your own server, can.

装

1准备一台服务器 A VPS running Ubuntu 22.04 or 24.04.
租一台云服务器（VPS），系统选 Ubuntu 22.04 或 24.04。记下它给你的 IP 地址和 root 密码。
2从电脑登上服务器 Windows: PowerShell. Mac: Terminal. Replace the IP with yours.
Windows 打开 PowerShell，Mac 打开「终端」。复制这行，把 你的服务器IP 换成自己的，回车：
ssh root@你的服务器IP
问 yes/no 就输 yes；问 password 就粘 root 密码回车（输密码时屏幕上不显示字，是正常的）。
你会看到：一行以 root@ 开头、末尾是 # 的提示符。
3建一个普通用户 The installer refuses to run as root. Make a normal user with sudo.
安装脚本不让用 root 跑，所以先建一个叫 nyx 的用户：
adduser nyx && usermod -aG sudo nyx && su - nyx
它会让你给 nyx 设一个密码（输两遍，同样不显示），后面问名字电话之类的一路回车跳过。
你会看到：提示符变成 nyx@…:~$。之后每一步都在这里做。
4一行安装 Run the installer. It asks three questions. 
curl -fsSL https://raw.githubusercontent.com/StarFold146/nyx/master/install.sh | bash
它会问三件事：
① Who answers — claude or codex? 用 Claude 订阅就输 claude，用 ChatGPT 订阅就输 codex。
② Your companion's name? 给它起的名字。
③ Your name? 你自己的名字。
中间要密码就输第 3 步给 nyx 设的那个。
你会看到：== 1/7 一直走到 == 7/7 Starting，最后一个框写着 Nyx is installed.，里面有 Address（网址）和 Key（钥匙）。
把 Address 和 Key 抄下来。Key 只有你能看，别发给别人。
5登录它的大脑 Log in to Claude Code or Codex with your subscription.
选了 claude 的：
cd ~/companion && claude
按提示用你的 Claude 账号登录，登完输 /exit 回车退出。
选了 codex 的：
先做这一步，不然登录会卡住不报错：在电脑或手机浏览器打开 chatgpt.com → 设置 → 安全（Security），打开「Codex 设备码登录 / device code authorization」那个开关。用的是团队/公司账号的，要管理员在工作区权限里开。（按钮名字各版本写法不太一样，找带 device code 的那个。）
First: chatgpt.com → Settings → Security → turn on device code authorization for Codex (workspace accounts: an admin enables it).
codex login --device-auth
它会给一个链接和一串码：手机打开链接，登 ChatGPT 账号，输那串码（码大约 15 分钟过期，过期就再跑一遍这行）。
6叫醒它 Start the companion and check it's running. 
sudo systemctl start nyx-companion && systemctl status nyx-companion --no-pager | head -5
你会看到：active (running)。
看到 failed 或红字：截图问人。
7手机上打开 Open the Address on your phone, enter the Key, add to home screen.
手机浏览器打开第 4 步的 Address，输入 Key。
iPhone：Safari 底下分享 → 添加到主屏幕。安卓 Chrome：右上 ⋮ → 安装应用。以后从桌面图标点开。

可选

A让 Nyx 里的 Codex 什么都能自己干 Codex only: full access. Anyone who can log into your Nyx then has root on this server.
只给 codex 用。默认它在只读沙盒里，装东西、改系统都做不了。在服务器上（nyx 用户下）粘这段：
echo 'BRIDGE_SANDBOX=danger-full-access' >> ~/nyx/relay/relay.env && echo 'nyx ALL=(ALL) NOPASSWD:ALL' | sudo tee /etc/sudoers.d/nyx >/dev/null && sudo chmod 440 /etc/sudoers.d/nyx && sudo visudo -c && sudo systemctl restart nyx-companion
你会看到：parsed OK。然后回 Nyx 跟它说：
运行 sudo -n whoami，告诉我结果。
它回 root 就成了。
这等于谁登进你的 Nyx，谁就有这台服务器的全部权限。只在你一个人用的机器上开，Key 守好。
B给它 API key，不用贴进聊天 Floating ball → Gauge → keys at the bottom.
聊天页点悬浮球 → 仪表 Gauge → 拉到最底下 keys / 密钥，填一个备注、名字（比如 GEMINI_API_KEY）和值。
存完只显示备注和最后四位。它用的时候按名字取，key 不进聊天，也不会因为在对话里要密码被拦。这里只列从这儿填进去的，装的时候写在设置文件里的那些不显示。
