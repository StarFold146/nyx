# 新手上路：从零租一台服务器，让你的 Claude 一直开着

这篇写给从没开过终端的人。一步只做一件事，命令整行复制粘贴就行。
每一步后面都有一句「你应该看到」，看到的不一样，先去最底下「常见的坑」找找。

整个东西长这样：

- **服务器（VPS）**：租来的一台电脑，放在机房里，二十四小时开着。你的 Claude 住在上面。
- **Claude Code**：Claude 在这台电脑上的「窗口」，用你自己的 Claude 订阅登录。
- **后台**：一个小程序，帮你手机和 Claude 之间传话。
- **网页**：就是这个仓库，装到手机桌面上像一个 app。

前 6 步带你走到「Claude 在服务器上一直开着」，后 4 步装后台和网页、在手机上打开。

---

## 第 0 步：你需要准备的

- 一个 Claude 的付费订阅（Pro 或 Max）。
- 一张能在网上付钱的卡，用来租服务器。
- 一台电脑。Windows、Mac 都行。手机也能做，但打命令很累，不推荐。

---

## 第 1 步：租一台服务器

去任意一家卖 VPS 的网站注册、买一台。挑的时候只看这几样：

- **系统**选 **Ubuntu 24.04**（或者 22.04）。别的系统这篇教程对不上。
- **配置**：2 核 CPU、2 GB 内存就够一个 Claude 住。想住好几个，选 4 GB。
- **机房位置**：选 Claude 能用的地区，比如新加坡、日本、美国。
  **别选中国大陆和香港**，Claude 在那里用不了。
- 登录方式如果让你选「密码」还是「SSH 密钥」，新手先选**密码**，自己设一个记牢。

买完以后，后台页面上会给你一串数字，长得像 `203.0.113.25`，这是服务器的 **IP 地址**。抄下来。

> 你应该看到：服务器状态是「运行中」，手里有一个 IP 地址和一个密码。

---

## 第 2 步：连上服务器

「连上」的意思是：在你自己电脑上开一个黑框框，你在里面打的字，会在服务器上执行。

**Mac**：打开「终端」（在启动台里搜 Terminal）。
**Windows**：按开始键，搜 **PowerShell**，打开。

在黑框框里输入下面这行，把 IP 换成你自己的，然后回车：

```
ssh root@203.0.113.25
```

第一次连会问你一句 `Are you sure you want to continue connecting`，输入 `yes` 回车。
然后它让你输密码。**输密码的时候屏幕上什么都不显示，这是正常的**，照打，打完回车。

> 你应该看到：最后一行变成类似 `root@你的服务器名:~#` 这样。这说明你已经在服务器里面了。

以后每次想进服务器，都是这一行命令。

---

## 第 3 步：给服务器打个补丁

刚租的服务器先更新一下。复制这行，粘贴，回车：

```
apt update && apt upgrade -y
```

它会刷很多字，等它停下来。中途如果弹出一个蓝色的框问你问题，直接按回车选默认的。

> 你应该看到：字停了，又回到 `root@...:~#` 那一行。

再装几个后面要用的小工具：

```
apt install -y curl git tmux
```

---

## 第 4 步：装 Claude Code

```
curl -fsSL https://claude.ai/install.sh | bash
```

装完以后，**把黑框框关掉，重新用第 2 步那行连一次**，让它认出新装的东西。

然后输入：

```
claude --version
```

> 你应该看到：一行版本号，比如 `2.1.xxx (Claude Code)`。

---

## 第 5 步：用你的订阅登录

```
claude
```

第一次打开它会问你几个问题（主题颜色之类），用方向键选，回车确认。
问到登录方式的时候，选 **Claude 账号登录（订阅）** 那一项。

它会给你一个很长的网址。**把网址复制下来，在你电脑或手机的浏览器里打开**，登录你的 Claude 账号，点同意。
网页会给你一串授权码，复制，回到黑框框里粘贴，回车。

> 你应该看到：Claude 跟你打招呼，下面有一个可以打字的框。随便说句话试试，它回你了就成功了。

想退出的时候，连按两次 `Ctrl + C`。

---

## 第 6 步：让它一直开着

现在有个问题：你一关黑框框，Claude 也跟着关了。
我们用一个叫 **tmux** 的小工具给它套一个「不会关的房间」。

```
tmux new -s claude
```

屏幕会清空，底下多一条绿色的条。这就是房间里面了。在房间里打开 Claude：

```
claude
```

现在**离开房间但不关它**：先按 `Ctrl + B`，松开，再按一下 `D`。

> 你应该看到：回到原来的黑框框，屏幕上写着 `[detached (from session claude)]`。

这时候你关掉黑框框、关电脑都没关系，Claude 还在服务器上开着。

想回去看它：

```
tmux attach -t claude
```

---

## 到这里你已经有了

一台一直开着的服务器，上面住着一个用你订阅登录的 Claude。
下面接着装后台、把网页放上去、在手机上打开。

> 想用 ChatGPT 订阅（Codex）而不是 Claude：第 4、5、6 步不用做，直接从第 7 步开始，第 7 步里选 `codex`。

---

## 第 7 步：一行装好剩下的全部

连上服务器（第 2 步那行），粘贴：

```
curl -fsSL https://raw.githubusercontent.com/StarFold146/nyx/master/install.sh | bash
```

它会问你三个问题，打字回车就行：

1. **Who answers**：用 Claude 就打 `claude`，用 ChatGPT 就打 `codex`。
2. **Your companion's name**：你的 AI 叫什么。
3. **Your name**：它怎么叫你。

中间它可能让你输一次服务器密码（`sudo` 要的），照输，屏幕上照样不显示。然后它会刷很多字，几分钟，等它停。

> 你应该看到：最后一大块框起来的字，里面有一行 **Address**（一个 `https://` 开头的网址）和一行 **Key**（一长串乱码）。
> **把这两样抄下来。** Key 就是进门的钥匙，别给别人看。

---

## 第 8 步：登录你的 AI

框里的「Two steps left」写着你还差的两步，照做：

**用 Claude 的**：

```
cd ~/companion && claude
```

如果第 5 步已经登过，它直接就能聊，打 `/exit` 退出。没登过就照第 5 步登一次。

**用 ChatGPT 的**：

```
codex login --device-auth
```

它会给你一个网址和一串码。**用手机浏览器打开那个网址**，登你的 ChatGPT 账号，把码填进去。

> 如果网页说没开「设备码登录」：电脑或手机浏览器打开 chatgpt.com（别用 app），左下角头像 → Settings → Security，找到写着 device code、后面列着 Codex 的那一项，打开，再回来重跑上面那行。

然后两种都一样，打：

```
sudo systemctl start nyx-companion
```

> 你应该看到：什么都不显示，直接回到 `root@...:~#` 那一行。没报错就是成功了。

---

## 第 9 步：在手机上打开

用手机浏览器打开第 7 步抄下来的 **Address**，在框里粘贴 **Key**，回车。

> 你应该看到：一张卡片翻过来，然后是主页。点「Chat」进去，跟它说句话，几秒钟它就回你了。

**放到桌面上**，用起来就像一个 app：

- **苹果**：用 Safari 打开 → 下面中间的分享按钮 → 「添加到主屏幕」。
- **安卓**：用 Chrome 打开 → 右上角三个点 → 「安装应用」或「添加到主屏幕」。

以后点桌面上那个图标就行。

---

## 第 10 步：让它变成你的

它是谁、怎么说话，写在服务器上的一个文件里：

- 用 Claude 的：`~/companion/CLAUDE.md`
- 用 ChatGPT 的：`~/companion/AGENTS.md`

想改就改，用大白话写就行：它叫什么、性格、你们的关系、你不喜欢它怎么说话。改完：

```
sudo systemctl restart nyx-companion
```

懒得在黑框框里改文件？直接在聊天里跟它说「帮我把你的人设改成……」，Claude 那边自己就能改。

---

## 网页里有什么

- **聊天页右下角的悬浮球**：点一下往左展开三颗。
  - **仪表**：现在用的模型、五小时和一周额度、上下文用了多少，点一下换模型。下面一条**压缩线**：上下文过了线，它先把要留的写进记忆，安静下来自动压缩，拖到最左是不划线。还有**压缩一下**、**开新窗口**（现在这个关掉重开，没写进记忆的不带过去）、**窗口**（以前的对话都在，点一个回去）。
  - **工程板**：想到 bug 和点子随手记。它要动网页或后台之前会先认领一张、写上改哪些文件，改完关掉。
    它干活的规矩写在 `docs/AI-WORKFLOW.md`：一次只拿一张，先备份，改完记进度、告诉你。往外发东西、动钥匙和权限、花钱、删你的数据，这几样它得等你当面点头。默认「当面」指在服务器上点头，聊天里说的不算；想让聊天里说的「可以」也算（钥匙和权限除外），在黑框框里打 `bash ~/nyx/consent.sh chat`，再 `sudo systemctl restart nyx-companion`，想改回来就换成 `person`。想让它在你不在的时候自己干活，跟它说一声「去把板上能做的做了」就行，标了「等你点头」的票它不会碰。
  - **心脏**：只读，看它的人设、记忆文件夹和后台代码，钥匙那几行自动打码。
- **抽屉**（主页左上角）：小家、底舱、生活几组，里面是杂物间、空房间、记忆、厨房这些。
- **记忆**：默认它把要记的写在服务器上 `~/companion/memory/` 里（心脏里能看）。想要真正的记忆，先装 [Ombre-Brain](https://github.com/P0luz/Ombre-Brain) 当底，再在上面接小红书 baci 老师的**记忆星图**当美化（她有教学视频）。装好把地址填进网页的 `config.js` 里 Memory 那一行的 `href`。
- **厨房**：写下锅具、调料、冰箱里有什么，点几样找菜谱，图鉴里没有就让它现写一道；做完拍照返图，它会看图写一句。

## 平时会用到的几行

| 想做什么 | 打这行 |
|---|---|
| 看它是不是在跑 | `systemctl status nyx-companion` |
| 重启它 | `sudo systemctl restart nyx-companion` |
| 看 Claude 那个窗口在干嘛 | `tmux attach -t companion`（看完 `Ctrl + B` 再按 `D` 离开） |
| 忘了钥匙 | `grep RELAY_SECRET ~/nyx/relay/relay.env` |
| 更新到最新版 | 再跑一遍第 7 步那行，它会接着装，不会弄丢你的东西 |

## 常见的坑

**`ssh` 那一步说 `Connection timed out` / 连接超时**
IP 抄错了，或者服务器还没开好。去服务器后台确认状态是「运行中」，IP 对不对。

**`ssh` 说 `Permission denied`**
密码错了。注意输密码时屏幕不显示，容易多打少打。实在忘了，去服务器后台找「重置密码」。

**Windows 说 `ssh 不是内部或外部命令`**
你的 Windows 太老了。去设置 → 应用 → 可选功能 → 添加「OpenSSH 客户端」，装完重开 PowerShell。

**`claude --version` 说 `command not found`**
第 4 步装完没有重新连。关掉黑框框，再 `ssh` 进去一次。

**登录时浏览器打不开那个网址 / 授权失败**
网址太长没复制全。在黑框框里用鼠标从头拖到尾再复制一次。

**按了 `Ctrl + B` 再按 `D` 没反应**
要先松开 `Ctrl + B`，再单独按 `D`，别一起按。

**第 9 步打开网址一直转圈 / 打不开**
刚装完 https 证书要一两分钟才申请下来，等一会儿再刷新。还不行，看服务器后台有没有防火墙挡了 80 和 443 端口，打开它们。

**输了 Key 说 That key didn't open it**
多复制了空格或者少了一截。用「平时会用到的几行」里那行把钥匙再查一遍。

**它不回话**
先 `systemctl status nyx-companion` 看是不是 running。Claude 的话 `tmux attach -t companion` 看那个窗口，常见是没登录或者停在一个要你按回车的问题上。

**Claude 说你所在的地区不支持**
服务器机房选在了不支持的地区。只能换一台机房在新加坡、日本、美国这些地方的服务器。
